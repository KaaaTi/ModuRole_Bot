ModuRole

A scalable, multi-guild Discord bot for live embed editing and modular role assignments.

🚀 Invite ModuRole

📖 Slash Commands

  • /help — Displays general instructions and documentation.
  • /embed create <name> — Opens an interactive builder panel to craft and publish an embed live.
  • /embed edit <name> [message_id] — Edit a template or update an already published live embed message.
  • /embed delete <name> — Deletes a template permanently.
  • /embed attach_role_toggle <name> <role> — Adds a 1-click toggle button (Zira style).
  • /embed attach_random_role <name> <role> — Adds a role into the gacha draw pool.
  • /embed attach_multi_role <name> <role> — Adds selectable roles to the long multi-choice dropdown tab.

🚀 Quick Start Guide

  1. Invite the bot and move the ModuRole role above the roles it manages.
  2. Run /embed create name:welcome to start an interactive visual session.
  3. Use /embed attach_... commands to link toggle buttons or role pools.
  4. Click Publish Live from the builder panel to post the embed to your channel.
